
# 🏏 IPL Data Analysis Dashboard

## 📊 Overview
This project analyzes IPL (Indian Premier League) data using Python and Streamlit.

## 🔍 Features
- Team performance analysis (matches won)
- Top batsmen based on total runs
- Strike rate calculation
- Runs per over trend analysis
- Interactive dashboard using Streamlit

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Streamlit

## 🚀 How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
